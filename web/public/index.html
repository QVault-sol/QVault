QVault Devnet

Quantum-safe custody for SOL and SPL tokens.

Every Solana address is an Ed25519 public key. A large enough quantum computer could compute the private key behind it. QVault keeps funds in a vault with no private key on-chain. It opens only with a hash-based one-time signature, computed in your browser.

Normal wallet

Ed25519 key. The public key is the address, visible to everyone. Breakable by a large quantum computer.

QVault

Program account with no private key. Opens only with a SHA-256 based one-time signature, verified on-chain.

Anatomy of a withdrawal

  1. Sign

    Your browser computes an 840-byte Winternitz signature over recipient, amount, token and next vault.

  2. Commit

    The program re-hashes the signature on-chain with SHA-256 and locks the destinations.

  3. Pay out

    The recipient gets the amount; 0.1 % goes to the treasury. No signature needed.

  4. Rotate

    Everything else moves to the next vault under a fresh one-time key.
